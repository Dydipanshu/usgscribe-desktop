# USGScribe for Windows

Voice dictation for ultrasound (USG) reports that types straight into MS Word, or any
other program where your cursor is.

**Download:** [USGScribe-Setup.exe](https://github.com/Dydipanshu/usgscribe-desktop/releases/latest/download/USGScribe-Setup.exe)
· Website: https://usgscribe.tunedloop.com

## How to use

1. Install and open USGScribe. It sits in the system tray (bottom-right of the taskbar).
2. Click in your Word report where the text should go.
3. Press **Ctrl+Shift+Space** and speak. Text appears each time you pause.
4. Press it again to stop.

Windows may show "Windows protected your PC" because the app is new. Choose
**More info**, then **Run anyway**.

This repository only hosts the installer releases.
